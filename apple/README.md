# Apple apps

- `CoachKit/`: Swift package shared by the iOS and watchOS apps. Wire protocol and platform-free logic only: no UIKit, HealthKit or LiveKit, so `swift test` runs on the command line.
- `iOS/`, `Watch/`, `project.yml`: arrive in M1, starting from Apple's "Building a multidevice workout app" sample. The Xcode project is generated by XcodeGen and not committed.
